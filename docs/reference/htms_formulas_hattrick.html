Hattrick · HTMS · HTMS28

HTMS y HTMS28

Reconstrucción de las formulaciones, tablas y lógica de cálculo utilizadas por la comunidad de Hattrick y por implementaciones como Foxtrick/Fantamondi.

1. ¿Qué es HTMS?

HTMS mide el valor acumulado de las habilidades de un jugador mediante una tabla de puntos por habilidad y por nivel. No es una suma directa de niveles ni una combinación lineal simple.

HTMS = f(GK) + f(DEF) + f(PM) + f(WING) + f(PASS) + f(SCOR) + f(SP)

En español:

  • GK: Portería
  • DEF: Defensa
  • PM: Jugadas
  • WING: Lateral
  • PASS: Pases
  • SCOR: Anotación
  • SP: Balón parado
Cada habilidad aporta una cantidad determinada de puntos según el nivel. El HTMS Ability es la suma de esos siete aportes.

4. HTMS28 — Potential

HTMS28 estima el potencial equivalente del jugador a los 28 años bajo unas condiciones de entrenamiento estándar.

HTMS28 = HTMS actual + puntos entrenables restantes hasta los 28 años

La lógica no intenta decidir en qué habilidad se entrenará al jugador. Convierte el tiempo de entrenamiento restante en puntos HTMS equivalentes.

6. Fórmula exacta antes de los 28 años

Definamos:

  • A = HTMS Ability actual
  • y = edad en años Hattrick
  • d = días adicionales de edad, entre 0 y 111
  • wy = puntos HTMS por semana correspondientes a esa edad
  • 1 año Hattrick = 112 días = 16 semanas

Para jugadores con y < 28:

HTMS28 = A + ((112 - d) / 7) · wy + 16 · Σ wk, para k = y+1,...,27

Finalmente, el resultado se redondea al entero más cercano.

7. Ejemplo: jugador de 17 años y 0 días

Para un jugador de 17 años exactos:

Potencial adicional = 16 · (10.00 + 9.92 + 9.81 + ... + 8.47)

El resultado aproximado es:

Potencial adicional ≈ 1641.44 puntos HTMS

Por tanto:

HTMS28 = HTMS Ability + 1641.44

Si el HTMS Ability fuera 0, el potencial redondeado sería aproximadamente 1641.

8. Ejemplo: jugador de 17 años y 50 días

Supongamos:

  • HTMS Ability = 400
  • Edad = 17 años y 50 días

Quedan:

112 - 50 = 62 días

Equivalentes a:

62 / 7 = 8.8571 semanas

A los 17 años se generan 10 puntos HTMS por semana:

8.8571 × 10 = 88.571 puntos

Luego se agregan las temporadas completas entre 18 y 27 años:

HTMS28 = 400 + 88.571 + 16 · (9.92 + 9.81 + ... + 8.47)

9. Condiciones implícitas del HTMS28

El cálculo de potencial supone aproximadamente:

  • Entrenador bueno / solid.
  • Asistentes con un nivel agregado equivalente cercano a 8.23.
  • 10% de stamina.
  • Entrenamiento continuo hasta los 28 años.
Por eso el HTMS28 no debe interpretarse como un atributo físico inmutable del jugador. Es una proyección basada en un supuesto de entrenamiento estándar.

10. Jugadores de 28 años o más

Para jugadores mayores, el cálculo se realiza en sentido inverso: se descuenta del HTMS actual el valor equivalente al entrenamiento transcurrido después de los 28 años.

Para un jugador de exactamente 28 años y d días:

HTMS28 = A - (d / 7) · w28

Para edades posteriores se descuentan también temporadas completas.

Las estimaciones para jugadores claramente mayores de 28 años son menos fiables como medida de “potencial”, por lo que su interpretación debe hacerse con cautela.

11. Resumen matemático

HTMS Ability

A = Σ Fs(Ls)

Donde:

  • s recorre las siete habilidades.
  • Ls es el nivel de la habilidad.
  • Fs es la columna correspondiente en la tabla HTMS.

HTMS28 para y < 28

P = A + ((112 - d)/7) · W(y) + 16 · Σ W(i) HTMS28 = round(P)
En términos de implementación, el sistema se reduce a una tabla de lookup para las habilidades y una tabla de velocidad de generación de puntos por edad.

12. Implicación práctica para HT Lens

Con estas formulaciones, HT Lens puede calcular localmente:

  • HTMS Ability actual.
  • HTMS28 Potential.
  • Diferencia entre Ability y Potential.
  • Ranking de jugadores por potencial.
  • Comparaciones entre jugadores de distinta edad.
  • Evolución histórica del HTMS si se almacenan snapshots de habilidades y edad.

Esto evita depender de una llamada externa a Fantamondi para obtener el resultado.
