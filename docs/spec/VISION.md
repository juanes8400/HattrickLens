# VISION

# Mission

Build the most comprehensive analytics platform ever created for Hattrick.org.

HT Lens is not merely a statistics viewer. It is a decision-support platform that helps managers make better sporting and financial decisions through data.

# Product Vision

HT Lens will evolve into the reference ecosystem for competitive Hattrick managers.

The platform will combine:

- Historical analytics
- Tactical analysis
- Training forecasting
- Financial planning
- Match simulation
- AI-assisted recommendations
- Long-term club planning

# Target Users

1. Casual managers seeking better insights.
2. Competitive league managers.
3. Top division clubs.
4. Youth development specialists.
5. Transfer market traders.
6. Data enthusiasts.

# Product Pillars

## Historical Intelligence

Every CHPP synchronization is preserved to enable trends and season-over-season analysis.

## Explainable Analytics

Every metric, recommendation and prediction must be traceable to explicit formulas.

## Modularity

Each calculation engine is independent and reusable.

## Performance

Fast synchronization, responsive UI and scalable architecture.

## Longevity

Configuration-driven business rules so future Hattrick changes require minimal code changes.

# Long-Term Goals

- Tactical simulator
- Monte Carlo match engine
- Automatic lineup optimizer
- Transfer recommendation engine
- Financial forecasting
- AI assistant
- Mobile application

# Success Criteria

A manager should be able to answer questions such as:

- Who should I train?
- When will this player pop?
- What is my strongest lineup?
- How strong is my next opponent?
- Should I buy or sell now?
- How will my finances evolve?

without leaving HT Lens.
