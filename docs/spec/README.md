# HT Lens

> **The Ultimate Analytics Platform for Hattrick.org**

## Vision

HT Lens is an advanced analytics platform for Hattrick managers, built on CHPP. It transforms raw game data into actionable insights through historical analysis, prediction, simulation and intelligent recommendations.

### Core Principles

- Data first
- Automation
- Transparency
- Extensibility
- Intelligence

## Main Features

- Team management
- Match analysis
- League analytics
- Training prediction
- Economy dashboard
- Stadium analytics
- Youth academy
- Transfers
- Match comparator
- AI-powered future modules

## Technology

**Backend:** FastAPI, PostgreSQL, Redis, Celery

**Frontend:** React, TypeScript, Tailwind CSS, ECharts

## Architecture

Frontend → REST API → Business Engines → Database → CHPP

Business logic is isolated into reusable engines (Positions, Training, Experience, Economy, Prediction).
